# John Conway's Game of Life

This coding challenge looks at creating John Conway's Game of Life simulation in Python. Before we get into the details of the code, let us review what this game is.

The Game of Life is as it says on the tin: a simulation that is meant to mimic basic life using only a few simple rules. This is is an example of cellular automata which evolve from an initial state and converge to some steady state in some finite period of time.
